# 1. Project Name: Workouts - FitLog

# 2. Description:

This is a Next.js project where some basic react tecnologies are used. This
project contains reponsive navbar, hero section, clickable library cards and a
footer. The whole website is fully responsive for all mobile, tablet and pc
versions.

# 3. Technologies:

Next.js Build the UI, App router(Next.js), Handle page navigation, Tailwind CSS,
Daisy ui library Styling and responsiveness

# 4. Features:

     1. The website is Responsive.
     2. clickable library cards for showing details.
     3. Showing toast on clicking the buttons.
     4. We can add and delete cards from my-plan.
     5. Storing data on localstorage.
